## About

The Green Orbit is an interactive agricultural decision-support platform created for the NASA Space Apps Challenge.

It combines NASA Earth observation data, climate signals, satellite imagery, crop information, and geographic context to help users make more informed and sustainable farming decisions.

## Features

- Search cities, countries, regions, or coordinates
- Explore agricultural profiles by country
- Interactive maps powered by OpenStreetMap
- NASA POWER climate insights
- Temperature, rainfall, and solar radiation data
- Satellite and Earth observation imagery
- Climate-aware crop recommendations
- Crop rotation planning
- Water conservation and soil health comparisons
- Nearby agricultural and circular-energy facilities
- Optional soil, field, and crop-health integrations
- Responsive design for desktop and mobile devices

## How It Works

1. Select a location using the search bar, globe, country explorer, or map.
2. The platform loads climate and geographic information.
3. NASA data provides temperature, rainfall, and solar insights.
4. The crop advisor evaluates suitable crops for the selected region.
5. The decision planner compares different crop rotation strategies.
6. Nearby agricultural and circular-economy facilities are displayed.

## Project Purpose

Farmers face changing rainfall patterns, rising temperatures, soil degradation, and limited access to reliable agricultural information.

The Green Orbit makes complex Earth observation data easier to understand by connecting climate information with local crops and practical farming decisions.

> This project is a decision-support prototype and does not replace local agricultural expertise.

## Limitations

This application is an experimental prototype. Results may be affected by:

- API availability
- Data coverage
- Location accuracy
- Limited agricultural datasets
- Regional differences in farming practices

Recommendations should be reviewed with local farmers, agronomists, and agricultural experts.
